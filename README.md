### 버전별 메모 & 업그레이드 옵션

- **①** 5600GT 내장그래픽으로 사무·영상·롤 저옵션 가능. 나중에 그래픽카드만 추가하면 ②급으로 확장 가능 (600W 파워 이미 포함).
- **②** RTX 5050이 RX 7600(현금 449,000원)보다 싸고 DLSS4 지원 → 5050 선택. 롤·발로란트·메이플은 충분, 배그는 FHD 중옵.
- **③** 업체 견적 대비 절감 폭이 크지 않음(현금 기준 약 8~14만원). 조립·AS가 부담되면 이 구간은 완본체도 고려할 만함.
  - 대안 GPU: RX 9060 XT 8GB (현금 599,000원, 판매처 1곳뿐)
- **④** 7500X3D는 FPS 게임(배그·발로)에서 7500F보다 체감 프레임↑. 16GB VRAM이라 신작 대응력이 좋음.
  - CPU를 7500F로 바꾸면 **−139,100원(현금)**, GPU를 RTX 5060 Ti 16GB(COLORFUL, 현금 955,000원)로 바꾸면 **+265,000원**
- **⑤** RX 9070(16GB)이 RTX 5070(12GB, 현금 1,220,000원)보다 **26만원 저렴**하면서 VRAM이 큼.
  - RTX 5070 선호(DLSS·방송 NVENC) 시 +263,000원 / RX 9070 XT(현금 1,260,000원) +303,000원
  - CPU 9800X3D(현금 572,600원)로 올리면 +186,200원

### 구매 전 체크리스트

1. **멀티팩 CPU는 쿨러 미포함** → 모든 견적에 쿨러를 포함시켰습니다.
2. **램 가격 폭등 중** (DDR5 8GB 약 17.5만원, 32GB 키트 62~71만원). 게이밍은 **8GB×2 듀얼채널** 권장. 16GB 단일 모듈(AGI 16GB 현금 306,000원)은 4.4만원 싸지만 싱글채널이라 성능 손해.
3. **현금가 대부분이 '현금결제 한정'** → 카드 결제면 '카드 최저' 열 기준으로 보세요.
4. 다나와 최저가 판매처가 부품마다 달라 **배송비가 부품마다 따로** 붙을 수 있습니다(표 가격은 각 판매처 배송비 포함). 한 쇼핑몰에서 몰아 사면 합배송 할인 가능.
5. 조립대행은 보통 2~3만원, Windows 11 Home은 별도.
